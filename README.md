# 短剧客户端 · 站点规则发布

此公开仓库只发布客户端可验证的签名规则包与说明，不包含应用源码、签名私钥、访问令牌、媒体文件或用户资料。

## 更新入口

客户端订阅地址：

https://raw.githubusercontent.com/longmaoqianxun/short-drama-rules/main/latest.json

- `latest.json`：当前发布的签名规则信封。
- `versions/vN.json`：历史发布包，用于版本追踪；客户端仍执行版本高水位检查，不接受降级重装。
- 当前首个发布包为 v4，schema / engine 均为 1，来源为黄果；接口规则与现有可用内置规则一致。

## 客户端处理

客户端使用编入应用的 Ed25519 公钥验证 payload 和 signature，不从此仓库下载新的受信密钥。下载失败、签名错误、版本不兼容或规则过期时保留本机可用规则。新规则先试用，实际解码并播放前进后确认，失败回退。

规则只是受限制的接口路径和字段映射，不运行远程脚本，不扩大应用的网络权限，也不提供第三方视频内容。更新下载不要求 GitHub 登录，不需要客户端携带 GitHub 令牌。

## 维护约定

在维护者私有开发环境中准备规则、离线签名并验证后，再发布到本仓库。不能提交私钥或 GitHub 访问令牌。递增版本号，不覆盖已发布历史包；修复被退回的版本时必须发布更高版本。单次提交更新 latest 与对应历史包，保留可审计记录。

发布新规则不会强制重启客户端或切换正在播放的视频。此仓库的发布版本不代表所有来源服务器及网络线路永久可用。
